何为“计白当黑”？

在东方禅意版面中，留白不等于“空白”。空白是具有张力的设计元素。四周留白能让核心色彩与文字获得宗教器物般的端庄感。

01/

东方禅意之美学心法

中国传统色设计不应是“复古堆砌”，而是**用现代精准的几何骨骼承载千年的风雅余韵**。整体遵循“简、远、凝、润”四大核心心法：

简 · 拒绝多余雕饰

不使用大面积多色渐变，不采用生硬的强投影或多层描边。通过极其纤细的墨线（1px）与纯净的留白建立边界。

远 · 意境深远留白

页面的纵向间距、文字与容器边距，必须比常规后台管理页面宽 1.5 倍以上。给眼睛呼吸与冥想的空间。

凝 · 精准的朱砂锚点

在一个视觉层级中，高纯度的朱砂红（Cinnabar Seal）至多出现两次。如古画中的红色落款，是极静空间中的一声钟鸣。

润 · 润物细无声

交互变化不使用唐突的弹跳或极快的瞬间切换，而是使用 400ms 至 500ms 的缓入缓出过渡（Cubic Bezier），如墨入水。

02/

色彩基础变量与系统架构

背景必须保持优雅温润，而不是耀眼的死白或生硬的数码灰。下面是本规范的黄金代号和 OKLch / RGB 参数：

Xuan
宣纸素底 (Background) --bg-paper
oklch(98% 0.005 85) / #FAF8F5

用于整体大底。模拟未漂白的手工竹浆宣纸纤维色调。

徽州松烟墨 (Text / Foreground) --fg-ink
oklch(18% 0.01 70) / #2B2B2B

用于文字、重点刻线。保留徽墨温润、富有层次的碳墨色泽。

大红朱砂印 (Accent Red) --accent-cinnabar
oklch(50% 0.18 30) / #C12C1F

主要强调色。源自天然辰砂矿物染料，纯正夺目，常作印信之章。

描金织锦 (Secondary Gold) --accent-gold
oklch(78% 0.12 85) / #D4AF37

次要强调/高光。富贵而不喧哗的亚光金，用于微章、卡边修饰。

// CSS:root 核心配色定义
:root {
  --bg-paper: oklch(98% 0.004 85);
  --fg-ink: oklch(18% 0.01 70);
  --accent-cinnabar: oklch(50% 0.18 30);
  --border-ink: oklch(20% 0.01 70 / 8%);
}

宋体风流与等宽对照

排版系统的灵魂在于**“文理分明”**。展示性的大标题、竖排诗词必须采用宋体（Songti CJK）；而具体色值、代码等现代测量数据，必须采用利落、可读性极强的等宽体。
